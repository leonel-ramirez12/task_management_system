
task management is a RESTful backend application built with Node.js and Express.js and mysql
It provides user authentication, task management, and email functionality using a modular and scalable structure.

3rd part module that i used
Node.js
Express.js
MySQL
JWT Authentication
bcrypt
Joi
Nodemailer
dotenv
CORS

Features
User registration and login
Secure password hashing
JWT-based authentication
Task CRUD operations
Email sending support
Request validation
Unified success and error responses
Clean modular architecture

to run this project 
1)npm i
2)create the .env file
3)npm run dev
